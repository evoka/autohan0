# 판단 정확도 개선 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 숫자·한 글자·약어·따옴표·코드 토큰 뒤의 한글, URL, A 모드 기호를 바로잡고, 2단계 학습과 앱별 엄격 모드를 더하되 "바꾸면 안 되는 것"은 하나도 더 바꾸지 않는다.

**Architecture:** 엔진(`packages/engine`)의 후보 생성(`Engine.candidates`)과 점수(`Scorer`)에 규칙을 더하고, 자판(`Layout`)에 "기호는 QWERTY 유지" 옵션을 둔다. 평가 틀(`eval/harness.ts`, `test/guard.test.ts`)을 먼저 두어 과제마다 회귀를 잰다. macOS 쪽은 엄격 모드 플러밍(Store → Controller → EngineBridge → host-jsc)만 바뀐다.

**Tech Stack:** TypeScript(vitest), Swift(SwiftPM), JavaScriptCore 번들(`npm run build:jsc`)

**Spec:** `docs/superpowers/specs/2026-10-22-accuracy-design.md`

## Global Constraints

- 코드 식별자·주석은 영어, 테스트 이름·README는 한국어 (SPEC 6절).
- `packages/engine`은 DOM/Node 의존 없음. 키당 평균 처리 시간 0.1ms 미만(perf.test.ts 23번) 유지.
- `npm test` 85개 + 새 guard 모두 통과. en.json 단어 사전 변경 상한(`EN_CHANGE_CEILING`)은 과제마다 올리지 않는다.
- 참고 저장소(`../ref`)의 코드·데이터는 복사하지 않는다(Tacit은 AGPL).
- 커밋 메시지 끝: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
